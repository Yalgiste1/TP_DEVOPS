# Apprentissages

## Partie 0: Préparer votre environnement

L'objectif de cet exercice est de vérifier que tous les outils nécessaires (go, git, docker, docker-compose) sont bien installés et prêts sur la machine.

### Problème rencontré et pourquoi il est survenu

Aucun problème particulier. Tous les outils fonctionnaient correctement après l'installation des prérequis.

### Solution appliquée et pourquoi cette solution fonctionne

Exécution des commandes de vérification (`go version`, `git --version`, `docker --version`, `docker compose version`) dans le terminal pour valider l'environnement avant de commencer.

### Ce que j'ai appris

- Vérifier l'installation et les versions de sa stack DevOps avant de lancer un projet.
